MEDIUM
  1. Open https://medium.com/new-story
  2. Type the title from the source front matter (Medium never fills it).
  3. Open .crosspost/host-react-saas-github-pages/medium.html in a browser, select all, copy,
     and paste into the Medium body. Tables are PNG images hosted on
     raw.githubusercontent.com, and Medium re-hosts them.
  4. Add topics and publish.

  1. builder.aws.com -> + -> Article.
  2. Title: .crosspost/host-react-saas-github-pages/builder-title.txt
  3. Description: .crosspost/host-react-saas-github-pages/builder-description.txt
  4. Paste the body from .crosspost/host-react-saas-github-pages/builder.html (tables render natively).
  5. Tags (max 5): .crosspost/host-react-saas-github-pages/builder-tags.txt
  6. Upload the cover: content/post/host-react-saas-github-pages/cover.jpg
     (recommended 1200x675).

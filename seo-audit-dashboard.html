Technical SEO — Findings (score 13/20)

Scope: sampled ~12 live URLs (home, 3 articles, taxonomies, search, 404, sitemaps, robots, llms.txt) + full source repo inspection. Not a full crawl of all ~210 URLs. No GSC access — indexing status is inferred, not measured.
Critical CLS ≈ 1.0 on homepage and article pages

Affected URL: https://f9xr.org/dev9b/ and article templates (all pages)

Evidence: Chrome DevTools performance trace: CLS 1.00–1.01 (threshold: ≤0.1). Root causes identified by the profiler: unsized cover image (cover.jpg has width/height attributes but layout reserves space late), non-composited CSS animations subsection-left-fade/subsection-right-fade animating --edge-fade-size custom properties, and Geist font swap shift.

Why it matters: CLS is a Core Web Vital; ~1.0 fails the "Good" threshold by 10×. On a small site this is the single biggest measurable quality-signal deficit and directly affects rankings and user trust.

Fix: (1) Add explicit width/height + aspect-ratio to all card/cover images in the theme templates; (2) animate only compositor-friendly properties (opacity/transform) or use @property-registered custom properties; (3) add font-display: optional or size-adjust fallback metrics for Geist; (4) reserve space for the reader toolbar and TOC before hydration.

Effort: Low–Medium (theme CSS/templates) · Priority: 1

Critical Sitemap URLs use http:// while canonicals use https://

Affected URL: https://f9xr.org/dev9b/sitemap.xml (all ~210 entries) and dev9b/robots.txt sitemap line

Evidence: Sitemap entries read http://f9xr.org/dev9b/... (verified). Live pages self-canonical to https:// (verified via ). JSON-LD og:url and entity @ids also use http:// while the canonical tag uses https://.

Why it matters: Sitemap URLs disagreeing with canonical protocol sends conflicting signals, splits entity identity between http/https versions, and wastes crawl budget on the non-canonical scheme.

Fix: Set baseurl = "https://f9xr.org/dev9b/" in config/_default/config.toml and rebuild. This aligns sitemap, og:url, JSON-LD @ids, share links and RSS links to https in one change. The site's own Hugo SEO guide already recommends exactly this.

Effort: Trivial · Priority: 1

Critical Root domain sitemap does not include Dev9b; dead sitemap references

Affected URL: https://f9xr.org/sitemap.xml · https://f9xr.org/robots.txt

Evidence: Root sitemap lists 54 URLs of the marketing site, zero containing /dev9b/ (verified). Root robots.txt declares Sitemap: sitemap-image.xml and sitemap-video.xml — sitemap-image.xml returns 404 (verified). Root robots.txt contains Agentmap:, an unknown directive flagged by Lighthouse ("robots.txt is not valid — line 149").

Why it matters: Dev9b lives on a subdirectory of f9xr.org but is invisible to the root-domain sitemap/robots surface that most crawlers read first. Broken sitemap references waste discovery.

Fix: Add Sitemap: https://f9xr.org/dev9b/sitemap.xml to root robots.txt; remove or fix the sitemap-image/video references; move the Agentmap: line into a comment or the ai-catalog link relationship (it is not a standard robots.txt directive).

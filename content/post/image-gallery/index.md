Dev9b supports interactive image galleries powered by [PhotoSwipe](https://photoswipe.com/). Create beautiful image collections using Markdown syntax.

The syntax was inspired by [Typlog](https://typlog.com/).

## Requirements

The image must be in the **same directory** as the Markdown file. External images are not supported.

## Syntax

```markdown
![Image 1](1.jpg) ![Image 2](2.jpg)
```

## Result

![Image 1](1.jpg) ![Image 2](2.jpg)

## Adding Images to Your Articles

1. Place images in the same directory as your `index.md`
2. Reference them with `![alt text](filename.jpg)`
3. Images will automatically become an interactive gallery

> Tip: Use high-quality images with consistent dimensions for the best gallery experience.
